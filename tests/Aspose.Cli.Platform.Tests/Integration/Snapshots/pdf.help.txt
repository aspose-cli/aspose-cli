## aspose-cli pdf --help
Description:
  PDF automation with page, security and fixed-layout semantics.

Usage:
  aspose-cli pdf [command]

Commands:
  inspect <file>   Show PDF structure, security state and properties.
  read <file>      Read a bounded page-text window.
  search <file>    Search PDF text and return page rectangles.
  convert <file>   Convert selected PDF pages to a supported format.
  render <file>    Render one or more PDF pages.
  create <file>    Create a PDF from exactly one source family.
  merge <files>    Merge PDF inputs in order.
  split <file>     Split a PDF into an atomic output set.
  extract <file>   Extract bounded PDF assets, text, tables or form data.
  edit <file>      Apply one validated, atomic PDF operation batch.
  validate <file>  Validate a PDF against a PDF/A profile.
  sign <file>      Apply a PKCS#7 signature and verify the saved signature field.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf inspect report.pdf --sample --detail permissions forms signatures
  aspose-cli pdf read report.pdf --pages 1-5 --content layout --output-format json
  aspose-cli pdf edit report.pdf --ops ops.json --out reviewed.pdf
  aspose-cli pdf sign reviewed.pdf --certificate signer.pfx --certificate-password-env PDF_SIGNING_PASSWORD --out approved.pdf

Learn more:
  aspose-cli docs pdf/editing       fixed-layout operations and safe mutation
  aspose-cli docs pdf/verification  read-back, rendering and PDF/A evidence
  aspose-cli schema v2/pdf/ops      the operation JSON schema


## aspose-cli pdf convert --help
Description:
  Convert selected PDF pages to a supported format.

Usage:
  aspose-cli pdf convert <file> [options]

Arguments:
  <file>  PDF document to open.

Options:
  --to <to>                      Target PDF export format. Default: the --out extension's format. Values: docx, epub, html, jpeg, md, pdfa-1b, pdfa-2b, pdfa-3b, png, pptx, svg, tiff, txt, xlsx, xps.
  --pages <pages>                Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page.
  -o, --out <out>                Output path; defaults to a sibling using the target extension.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the PDF.
  --password-stdin               Read the password for the PDF from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf convert report.pdf --out report.docx
  aspose-cli pdf convert report.pdf --to pdfa-2b --out archive.pdf
  aspose-cli pdf convert report.pdf --pages 1-3 --out summary.md

Learn more:

## aspose-cli pdf edit --help
Description:
  Apply one validated, atomic PDF operation batch.

Usage:
  aspose-cli pdf edit <file> [options]

Arguments:
  <file>  PDF document to open.

Options:
  --ops <ops>                    The ops JSON, an object with ops or the bare array of operations: a path to the document, '-' to read it from stdin, or the document itself when the value starts with { or [ (inline). To name a file whose name starts with '[', prefix it with ./ . At most 10000 operations. Vocabulary: aspose-cli schema v2/pdf/ops.
  --if-match <if-match>          Require the current input SHA-256 fingerprint before editing.
  --best-effort                  Keep successful operations, report failures, and exit 8.
  --verify                       Read the staged output back and check the effect of each form, redaction, bookmark, metadata, attachment and page operation.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --backup                       Create a non-overwriting backup before an in-place write.
  --dry-run                      Check the input, the output and the operations, and apply the operations in memory, without writing any file. A dry run that succeeds does not guarantee that the edit succeeds.
  --password <password>          Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the PDF.
  --password-stdin               Read the password for the PDF from the first line of stdin.
  --encrypt <encrypt>            Password for the output PDF. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output PDF.
  --encrypt-stdin                Read the password for the output PDF from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf edit report.pdf --ops ops.json --out reviewed.pdf --verify
