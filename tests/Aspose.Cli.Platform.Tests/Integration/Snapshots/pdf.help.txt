## aspose-cli pdf --help
Description:
  Read, edit, convert and render PDF documents through the Aspose.PDF object model.

Usage:
  aspose-cli pdf [command]

Commands:
  read <file>      Read a PDF's objects, each with every row of the object table, and its inventory.
  search <file>    Search the text of a PDF's pages with the engine's TextFragmentAbsorber; each hit names the page's text and gives the engine's rectangle of the match.
  convert <file>   Convert a PDF, or an HTML page the engine imports, to another format with the engine's call for it. An html output is one file: it holds its images, fonts and styles itself.
  render <file>    Render one or more PDF pages.
  create <file>    Create a document: the engine's new document, or a copy of a template saved in the output's format.
  merge <files>    Merge PDF inputs in order with the engine's PdfFileEditor.Concatenate.
  split <file>     Split a PDF by page ranges, each part a new document with Pages.Add of its pages; every part is written or none.
  extract <file>   Extract a PDF's images, attachments, tables or form data into a directory with the engine's calls for them; the page text is read with 'aspose-cli pdf read --kind text'.
  edit <file>      Apply a batch of set, add, delete and do operations to a PDF; nothing is written when one fails.
  validate <file>  Validate a PDF against a PDF/A profile with Document.Validate; the result holds its return value and its log.
  sign <file>      Sign a PDF with a PKCS#7 signature through PdfFileSignature.Sign, and read the new signature back from the saved file.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf read report.pdf
  aspose-cli pdf read report.pdf --at page/1/text
  aspose-cli pdf edit form.pdf --ops ops.json --out filled.pdf

Learn more:
  aspose-cli schema v2/pdf/ops/directory  the object table: kinds, addresses, rows, adds and actions


## aspose-cli pdf convert --help
Description:
  Convert a PDF, or an HTML page the engine imports, to another format with the engine's call for it. An html output is one file: it holds its images, fonts and styles itself.

Usage:
  aspose-cli pdf convert <file> [options]

Arguments:
  <file>  PDF document to open.

Options:
  --to <to>                                      Target format. Default: the --out extension's format, except pdfa-1b, pdfa-2b, pdfa-3b, which only --to chooses. pdfa-1b, pdfa-2b, pdfa-3b write .pdf. Values: docx, epub, html, md, pdf, pdfa-1b, pdfa-2b, pdfa-3b, pptx, tiff, txt, xlsx, xps.
  --pages <pages>                                Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page. Only with --to html or tiff.
  --convert-error-action <convert-error-action>  What Document.Convert does with what the PDF/A profile does not allow, a member name of the engine's ConvertErrorAction, such as Delete or None. Required for a pdfa output.
  -o, --out <out>                                Output path; defaults to a sibling using the target extension.
  --overwrite                                    Replace the output file if it already exists.
  --password <password>                          Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>                  Name of an environment variable holding the password for the PDF.
  --password-stdin                               Read the password for the PDF from the first line of stdin.
  --font-dir <font-dir>                          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf convert report.pdf --out report.docx
  aspose-cli pdf convert report.pdf --to pdfa-2b --convert-error-action Delete --out archive.pdf
  aspose-cli pdf convert page.html --out page.pdf

Learn more:
  aspose-cli schema v2/pdf/convert-result  the fields of the convert result

  --overwrite                    Replace the output file if it already exists.

  --password <password>          Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the PDF.
  --password-stdin               Read the password for the PDF from the first line of stdin.
  --encrypt <encrypt>            Password for the output PDF. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output PDF.
  --encrypt-stdin                Read the password for the output PDF from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf edit form.pdf --ops ops.json --out filled.pdf
  aspose-cli pdf edit report.pdf --in-place --ops ops.json

Learn more:
  aspose-cli schema v2/pdf/ops/directory  the kinds and their rows, the adds and the actions an operation names
  aspose-cli schema v2/pdf/ops/<name>     one kind, add or action in full

## aspose-cli pdf extract --help
Description:
  Extract a PDF's images, attachments, tables or form data into a directory with the engine's calls for them; the page text is read with 'aspose-cli pdf read --kind text'.

Usage:
  aspose-cli pdf extract <file> --what <what> --out-dir <out-dir> [options]

Options:

  --pages <pages>                                      Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page. Only with --what images or tables.
  --bom                                                Start each table's CSV with a UTF-8 byte order mark, so Excel reads its non-English text correctly; only with --what tables. Default: UTF-8 without one.
  --out-dir <out-dir> (REQUIRED)                       Safe extraction directory.
  --overwrite                                          Replace the output file if it already exists.
  --password <password>                                Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>                        Name of an environment variable holding the password for the PDF.
  --password-stdin                                     Read the password for the PDF from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf extract report.pdf --what images --out-dir images
  aspose-cli pdf extract report.pdf --what tables --pages 2-4 --bom --out-dir tables
  aspose-cli pdf extract form.pdf --what forms --form-format json --out-dir form-data

Learn more:
  aspose-cli schema v2/pdf/extract-result  the fields of the extract result

  aspose-cli pdf read report.pdf
  aspose-cli pdf read report.pdf --kind field
  aspose-cli pdf read report.pdf --at page/1/text
  aspose-cli pdf read report.pdf --kind text --max-objects 20

## aspose-cli pdf sign --help
Description:
  Sign a PDF with a PKCS#7 signature through PdfFileSignature.Sign, and read the new signature back from the saved file.

Usage:
  aspose-cli pdf sign <file> --certificate <certificate> --page <page> [options]

Arguments:
  <file>  PDF document to open.

Options:
  --certificate <certificate> (REQUIRED)                 PKCS#12 certificate path (.pfx or .p12).
  --certificate-password-env <certificate-password-env>  Name of an environment variable holding the password for the PKCS#12 certificate.
  --certificate-password-stdin                           Read the password for the PKCS#12 certificate from the first line of stdin.
  --visible                                              The visible parameter of PdfFileSignature.Sign: the signature has an appearance on the page. Takes --rect.
  --page <page> (REQUIRED)                               The page parameter of PdfFileSignature.Sign, from 1.
  --rect <rect>                                          The rectangle of a visible signature, the engine's System.Drawing.Rectangle the call takes: x,y,width,height in whole points, x and y the lower-left corner in the page's user space. Required with --visible.
  --reason <reason>                                      PKCS7.Reason.
  --location <location>                                  PKCS7.Location.
  --contact <contact>                                    PKCS7.ContactInfo.
  --font <font>                                          SignatureCustomAppearance.FontFamilyName of a visible signature; not given, the engine's default appearance.
  -o, --out <out>                                        Signed PDF path. Default: <input>.signed.pdf.
  --overwrite                                            Replace the output file if it already exists.
  --password <password>                                  Password for the input PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>                          Name of an environment variable holding the password for the input PDF.
  --password-stdin                                       Read the password for the input PDF from the first line of stdin.
  --font-dir <font-dir>                                  Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf sign contract.pdf --page 1 --certificate signer.pfx --certificate-password-env PDF_SIGNING_PASSWORD
  aspose-cli pdf sign contract.pdf --page 2 --certificate signer.pfx --certificate-password-stdin --visible --rect 36,36,180,60 --reason Approved --out signed.pdf

Learn more:
  aspose-cli schema v2/pdf/sign-result  the fields of the sign result


## aspose-cli pdf split --help
Description:
  Split a PDF by page ranges, each part a new document with Pages.Add of its pages; every part is written or none.

Usage:
  aspose-cli pdf split <file> --by <by> --out-dir <out-dir> [options]

Arguments:
  <file>  PDF document to open.

Options:
  --by <pages> (REQUIRED)         How to divide the document: one part per page, per --every N of them or per --groups group.
  --every <every>                 Pages per part with --by pages. Default: 1.
  --groups <groups>               A page group with --by pages, one part each; repeat for more, such as --groups 1-3 --groups 4-6.
  --pages <pages>                 Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page. Only with --by pages.
  --out-dir <out-dir> (REQUIRED)  Directory that receives the parts, named <stem>.<n>.pdf.
  --overwrite                     Replace the output file if it already exists.
  --password <password>           Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the PDF.
  --password-stdin                Read the password for the PDF from the first line of stdin.
  --encrypt <encrypt>             Password for every output PDF. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>     Name of an environment variable holding the password for every output PDF.
  --encrypt-stdin                 Read the password for every output PDF from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli pdf split report.pdf --by pages --every 2 --out-dir parts
  aspose-cli pdf split report.pdf --by pages --groups 1-3 --groups 4-6 --out-dir parts

Learn more:
