## aspose-cli pdf --help
Description:
  PDF automation with page, security and fixed-layout semantics.

Usage:
  aspose-cli pdf [command] [options]

Options:
  -?, -h, --help                              Show help and usage information
  -f, --output <compact|json|markdown|table>  Output format: json (contract envelopes), compact (the same JSON on one line), table (human text) or markdown. Default: table on a terminal, json when redirected.
  -q, --quiet                                 Suppress warnings and notices on stderr (errors still print).
  -v, --verbose                               Emit structured JSONL diagnostics (timing, error codes) to stderr; stdout is untouched.
  --license <license>                         Path to an Aspose license file; overrides every other license source.
  --license-mode <auto|evaluation>            auto (default) resolves the license sources in order; evaluation reads none of them and runs this command in evaluation mode. Cannot be combined with --license.
  --workdir <workdir>                         Base directory for relative paths. Default: the current directory.
  --timeout <timeout>                         Set one command deadline in seconds. Before exit 9, supervised work is stopped and staged outputs are recovered.
  --max-input-bytes <max-input-bytes>         Maximum bytes admitted for one input before product runtime initialization (default 1073741824; hard maximum 4294967296).

Commands:
  inspect <file>   Show PDF structure, security state and metadata.
  query            Query bounded PDF pages, forms or text matches.
  convert <file>   Convert selected PDF pages to a supported format.
  render <file>    Render one or more PDF pages.
  create <file>    Create a PDF from exactly one source family.
  merge <files>    Merge PDF inputs in order.
  split <file>     Split a PDF into an atomic output set.
  extract <file>   Extract bounded PDF assets, text, tables or form data.
  edit <file>      Apply one validated, atomic PDF operation batch.
  validate <file>  Validate a PDF against a PDF/A profile.
  sign <file>      Apply a PKCS#7 signature and verify the saved signature field.

Examples:
  aspose-cli pdf inspect report.pdf --preview --detail permissions forms signatures
  aspose-cli pdf query pages report.pdf --pages 1-5 --mode layout --output json
  aspose-cli pdf edit report.pdf --ops ops.json --out reviewed.pdf
  aspose-cli pdf sign reviewed.pdf --certificate signer.pfx --certificate-password-env PDF_SIGNING_PASSWORD --out approved.pdf

Learn more:
  aspose-cli docs pdf/editing       fixed-layout operations and safe mutation
  aspose-cli docs pdf/verification  read-back, rendering and PDF/A evidence
  aspose-cli schema v2/pdf/ops      the operation JSON schema

  <file>  PDF document to open.

Options:
  --profile <pdfa-1b|pdfa-2b|pdfa-3b> (REQUIRED)  pdfa-1b, pdfa-2b or pdfa-3b.
  --password <password>                           Password for the PDF. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>                   Name of an environment variable holding the password for the PDF.
  --password-stdin                                Read the password for the PDF from the first line of stdin.
  -?, -h, --help                                  Show help and usage information
  -f, --output <compact|json|markdown|table>      Output format: json (contract envelopes), compact (the same JSON on one line), table (human text) or markdown. Default: table on a terminal, json when redirected.
  -q, --quiet                                     Suppress warnings and notices on stderr (errors still print).
  -v, --verbose                                   Emit structured JSONL diagnostics (timing, error codes) to stderr; stdout is untouched.
  --license <license>                             Path to an Aspose license file; overrides every other license source.
  --license-mode <auto|evaluation>                auto (default) resolves the license sources in order; evaluation reads none of them and runs this command in evaluation mode. Cannot be combined with --license.
  --workdir <workdir>                             Base directory for relative paths. Default: the current directory.
  --timeout <timeout>                             Set one command deadline in seconds. Before exit 9, supervised work is stopped and staged outputs are recovered.
  --max-input-bytes <max-input-bytes>             Maximum bytes admitted for one input before product runtime initialization (default 1073741824; hard maximum 4294967296).
