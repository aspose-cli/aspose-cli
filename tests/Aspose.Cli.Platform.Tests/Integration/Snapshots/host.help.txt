## aspose-cli --help
Description:
  Aspose CLI — high-fidelity file automation for people, scripts, and AI agents. Structured commands support --output-format json for stable, machine-readable results; explicit schema and docs documents remain raw.

Usage:
  aspose-cli [command] [options]

Options:
  --output-format <compact|json|markdown|table>  How results print: the contract envelope, indented or on one line, or human text. Default: human text on a terminal, the indented envelope when redirected.
  -q, --quiet                                    Suppress warnings and notices on stderr (errors still print).
  -v, --verbose                                  Emit structured JSONL diagnostics (timing, error codes) to stderr; stdout is untouched.
  --license <license>                            Path to an Aspose license file; overrides every other license source.
  --license-mode <auto|evaluation>               evaluation reads no license source and runs this command in evaluation mode; by default the license sources are resolved in order. Cannot be combined with --license.
  --workdir <workdir>                            Base directory for relative paths. Default: the current directory.
  --timeout <timeout>                            Set one command deadline in seconds. Before exit 9, supervised work is stopped and staged outputs are recovered.
  --max-input-bytes <max-input-bytes>            Maximum bytes admitted for one input before product runtime initialization. Default: 1073741824. Range: 1-4294967296.
  -h, --help                                     Show help and usage information
  --version                                      Show version information

Commands:
  app                               Open the local file workspace in a browser.
  preview                           Watch files in the local viewer and follow every change.
  review <file>                     Create a portable static evidence directory for visual inspection.
  cells                             Spreadsheet operations (Excel and friends) with engine-grade fidelity.
  pdf                               PDF automation with page, security and fixed-layout semantics.
  slides                            Presentation automation with slide, layout and notes semantics.
  words                             Word-processing document automation with layout fidelity.
  license                           Inspect and manage the Aspose license used by the CLI.
  capabilities <product> <command>  Describe everything this build supports (products, verbs, formats), as data.
  doctor                            Diagnose the environment: runtime, resource budgets and output writability.
  skill                             List or install Agent Skills bundled with this binary.
  schema <id>                       List schema ids as an envelope, or print one raw JSON Schema document when an id is supplied.
  docs <topic>                      Print an offline reference document bundled with this binary.
  fonts                             Diagnose the font environment used for rendering.
  mcp                               Expose this CLI to a local MCP client over stdio.
  update                            Check or install a CLI release; no background checks are performed.

Examples:
  aspose-cli app open
  aspose-cli capabilities cells edit --output-format json
  aspose-cli review report.docx --max-items 50
  aspose-cli schema

Learn more:
  aspose-cli docs                    offline documentation bundled in this binary
  aspose-cli schema                  the available JSON Schema identifiers
  aspose-cli capabilities --summary  each product's commands, formats and operations

## aspose-cli review --help
Description:
  Create a portable static evidence directory for visual inspection.

Usage:
  aspose-cli review <file> [options]

Arguments:
  <file>  Source file to review; its content decides which product reads it.

Options:
  -o, --out <out>                             Evidence directory; defaults to <filename>.review beside the source.
  --overwrite                                 Replace the evidence directory if it already exists.
  --dry-run                                   Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --max-items <max-items>                     Maximum visual units rendered and listed in review.json. Range: 1-8192. [default: 256]
  --product <cells|pdf|slides|words>          Product that reads the file; by default, the one whose format the file's content matches.
  --view <auto|pages|sheets|slides|workbook>  Product view; auto uses the product's own view. Review renders only views made of images and refuses any other. [default: auto]
  --code <code>                               Report only findings of this check (a code from capabilities review.checks); repeat for several. Errors of other checks then do not fail the review. Accepts 65 values, listed in aspose-cli capabilities.
  --password <password>                       Password for the review source. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>               Name of an environment variable holding the password for the review source.
  --password-stdin                            Read the password for the review source from the first line of stdin.
  --font-dir <font-dir>                       Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli review report.docx
  aspose-cli review report.docx --out evidence --max-items 50 --output-format json
