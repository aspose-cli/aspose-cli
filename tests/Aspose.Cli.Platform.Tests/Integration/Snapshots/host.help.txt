## aspose-cli --help
Description:
  Aspose CLI — high-fidelity file automation for people, scripts, and AI agents. Structured commands support --output json for stable, machine-readable results; explicit schema and docs documents remain raw.

Usage:
  aspose-cli [command] [options]

Options:
  -f, --output <compact|json|markdown|table>  Output format: json (contract envelopes), compact (the same JSON on one line), table (human text) or markdown. Default: table on a terminal, json when redirected.
  -q, --quiet                                 Suppress warnings and notices on stderr (errors still print).
  -v, --verbose                               Emit structured JSONL diagnostics (timing, error codes) to stderr; stdout is untouched.
  --license <license>                         Path to an Aspose license file; overrides every other license source.
  --license-mode <auto|evaluation>            auto (default) resolves the license sources in order; evaluation reads none of them and runs this command in evaluation mode. Cannot be combined with --license.
  --workdir <workdir>                         Base directory for relative paths. Default: the current directory.
  --timeout <timeout>                         Set one command deadline in seconds. Before exit 9, supervised work is stopped and staged outputs are recovered.
  --max-input-bytes <max-input-bytes>         Maximum bytes admitted for one input before product runtime initialization (default 1073741824; hard maximum 4294967296).
  -?, -h, --help                              Show help and usage information
  --version                                   Show version information

Commands:
  app <file>                        Open the local file workspace in a browser.
  preview <file>                    Watch a file in the local viewer and follow every change.
  review <file>                     Create a portable static evidence directory for visual inspection.
  cells                             Spreadsheet operations (Excel and friends) with engine-grade fidelity.
  pdf                               PDF automation with page, security and fixed-layout semantics.
  slides                            Presentation automation with slide, layout and notes semantics.
  words                             Word-processing document automation with layout fidelity.
  license                           Inspect and manage the Aspose license used by the CLI.
  capabilities <product> <command>  Describe everything this build supports (products, verbs, formats), as data.
  doctor                            Diagnose the environment: runtime, resource budgets and output writability.
  skill                             List or install Agent Skills bundled with this binary.
  schema <id>                       List schema ids as an envelope, or print one raw JSON Schema document when an id is supplied.
  docs <topic>                      Print an offline reference document bundled with this binary.
  fonts                             Diagnose the font environment used for rendering.
  mcp                               Expose this CLI to a local MCP client over stdio.
  update                            Check or install a CLI release; no background checks are performed.

Examples:
  aspose-cli app
  aspose-cli capabilities --output json
  aspose-cli review <file> --max-items 50
  aspose-cli schema

Learn more:
  aspose-cli docs                        offline documentation bundled in this binary
  aspose-cli schema                      the available JSON Schema identifiers
  aspose-cli capabilities --output json  verbs, formats and operations as data
