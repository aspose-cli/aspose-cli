## aspose-cli cells --help
Description:
  Spreadsheet operations (Excel and friends) with engine-grade fidelity.

Usage:
  aspose-cli cells [command]

Commands:
  inspect <file>          Show structure and metadata of a workbook.
  query                   Read bounded workbook data without mutating the source file.
  create <file>           Create a new workbook.
  edit <file>             Apply a batch of edit ops atomically. Editable outputs: xlsx, xltx, xlsm, xltm, xlsb, xls, ods, csv, tsv, html, mhtml.
  compare <left> <right>  Compare stored workbook values and optional formula text; dates use raw serial numbers.
  convert <file>          Convert a workbook to another format.
  render <file>           Render a sheet, a range, or every visible sheet to images.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells inspect book.xlsx --output-format json

Learn more:
  aspose-cli docs cells/editing             the edit-operation vocabulary and recipes
  aspose-cli docs cells/workbook-standards  professional workbook construction guidance
  aspose-cli docs cells/verification        the spreadsheet delivery verification protocol
  aspose-cli schema v2/cells/ops            the operations JSON Schema


## aspose-cli cells compare --help
Description:
  Compare stored workbook values and optional formula text; dates use raw serial numbers.

Usage:
  aspose-cli cells compare <left> <right> [options]

Arguments:
  <left>   Baseline workbook.
  <right>  Candidate workbook to compare against the baseline.

Options:
  --compare <formulas|values>                What to compare; formulas adds the formula text to the cell results. [default: formulas]
  --max-diffs <max-diffs>                    Maximum differing cells to list across the entire workbook. Range: 1-1000000. [default: 1000]
  --left-password <left-password>            Password for the baseline file. Discouraged: visible in the process list; prefer --left-password-env.
  --left-password-env <left-password-env>    Name of an environment variable holding the password for the baseline file.
  --left-password-stdin                      Read the password for the baseline file from the first line of stdin.
  --right-password <right-password>          Password for the candidate file. Discouraged: visible in the process list; prefer --right-password-env.
  --right-password-env <right-password-env>  Name of an environment variable holding the password for the candidate file.
  --right-password-stdin                     Read the password for the candidate file from the first line of stdin.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells compare old.xlsx new.xlsx --output-format json
  aspose-cli cells compare old.xlsx new.xlsx --compare values --max-diffs 50

Learn more:
  aspose-cli docs cells/verification  comparing a workbook before and after a change


## aspose-cli cells convert --help
Description:
  Convert a workbook to another format.

Usage:
  aspose-cli cells convert <file> [options]

Arguments:
  <file>  Workbook to convert.

Options:
  --to <to>                      Target format: xlsx, xltx, xlsm, xltm, xlsb, xls, ods, csv, tsv, html, mhtml, pdf, xps, json, md. Default: the --out extension's format. Values: csv, html, json, md, mhtml, ods, pdf, tsv, xls, xlsb, xlsm, xlsx, xltm, xltx, xps.
  --sheet <sheet>                Convert only this sheet (supported for csv, tsv, md, pdf).
  --encoding <encoding>          Text encoding of a CSV or TSV input, such as gb18030, big5, shift_jis or windows-1252. Default: its byte order mark, else UTF-8 (other bytes are refused).
  --culture <culture>            Culture whose number and date formats a CSV or TSV input uses, such as de-DE for '1.234,56'. Default: invariant formats (a decimal comma is refused).
  --bom                          Start a CSV or TSV output with a UTF-8 byte order mark, so Excel reads its non-English text correctly. Default: UTF-8 without one.
  -o, --out <out>                Output path. Default: the input path with the target extension (with '.out' inserted when that would overwrite the input).
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.
  --encrypt <encrypt>            Password for the output file. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output file.
  --encrypt-stdin                Read the password for the output file from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells convert sales.csv --to xlsx
  aspose-cli cells convert erp-export.csv --to xlsx --encoding gb18030
  aspose-cli cells convert partner-orders.csv --to xlsx --culture de-DE
  aspose-cli cells convert book.xlsx --to csv --bom --out for-excel.csv
  aspose-cli cells convert book.xlsx --out report.pdf
  aspose-cli cells convert book.xlsx --to pdf --font-dir fonts --out report.pdf

Learn more:
  aspose-cli docs cells/report-from-csv  importing CSV into a workbook
  aspose-cli docs cells/overview         what each Cells command is for

## aspose-cli cells edit --help
Description:
  Apply a batch of edit ops atomically. Editable outputs: xlsx, xltx, xlsm, xltm, xlsb, xls, ods, csv, tsv, html, mhtml.

Usage:
  aspose-cli cells edit <file> [options]

Arguments:
  <file>  Workbook to edit.

Options:
  --ops <ops>                    The ops JSON, an object with ops or the bare array of operations: a path to the document, '-' to read it from stdin, or the document itself when the value starts with { or [ (inline). To name a file whose name starts with '[', prefix it with ./ . At most 10000 operations. Vocabulary: aspose-cli schema v2/cells/ops.
  --set <set>                    Set one cell as SHEET!CELL=VALUE; repeatable, applied after the --ops document. A VALUE starting with '=' is a formula; otherwise TRUE/FALSE and numbers are typed and anything else is text. Quote sheet names that need it: --set "'My Sheet'!A1=5". Example: --set "Sales!B3=42" --set "Sales!G2==E2*F2".
  --if-match <if-match>          Require the current input SHA-256 fingerprint before editing.
  --best-effort                  Keep successful operations, report failures, and exit 8.
  --verify                       Verify the staged output and report its cell changes and formula errors.
  --no-recalc                    Skip the automatic formula recalculation after applying the ops.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --backup                       Create a non-overwriting backup before an in-place write.
  --dry-run                      Check the input, the output and the operations, and apply the operations in memory, without writing any file. A dry run that succeeds does not guarantee that the edit succeeds.
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.
  --encrypt <encrypt>            Password for the output file. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output file.
  --encrypt-stdin                Read the password for the output file from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells edit book.xlsx --in-place --set "Sales!B3=42" --set "Sales!G2==E2*F2"
  aspose-cli cells edit book.xlsx --in-place --ops '{"ops":[{"op":"set_values","sheet":"Sales","range":"A1","values":[[1]]}]}'
  aspose-cli cells edit book.xlsx --in-place --backup --verify --ops ops.json

  aspose-cli schema v2/cells/ops      the operations JSON vocabulary

## aspose-cli cells query range --help

  <file>  Workbook to read.

Options:
  --sheet <sheet>                        Sheet to read. Default: the active sheet.
  --range <range>                        Window to read, e.g. A1:F50 or Sales!A1:F50. Default: the used range, subject to --max-cells.
  --scope <formulas|full|styles|values>  Projection scope: formulas adds f; the style scope adds styleId and the style pool. [default: values]
  --max-cells <max-cells>                Cell budget per call. Range: 1-1000000. [default: 10000]
  --password <password>                  Password for the workbook. Discouraged: visible in the process list; prefer --password-env.

Examples:
  aspose-cli cells query range book.xlsx --range Sales!A1:D10 --scope values --output-format json
  aspose-cli cells query range book.xlsx --sheet Sales --scope formulas --output-format json


## aspose-cli cells query search --help
Description:
  Find cells whose value or formula matches a pattern.

Usage:
  aspose-cli cells query search <file> --pattern <pattern> [options]

Arguments:
  <file>  Workbook to search.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --scope <both|formulas|values>  Where to search: the cell results, the formula text or both. [default: values]
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --sheet <sheet>                 Restrict to one sheet. Default: all sheets.
  --password <password>           Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the workbook.
  --password-stdin                Read the password for the workbook from the first line of stdin.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells query search book.xlsx --pattern TODO --output-format json
  aspose-cli cells query search book.xlsx --pattern SUM --scope formulas --max-hits 10


## aspose-cli cells render --help
Description:
  Render a sheet, a range, or every visible sheet to images.

Usage:
  aspose-cli cells render <file> [options]

Arguments:
  <file>  Workbook to render.

Options:
  --to <jpeg|png|svg>            Image format. Default: the --out extension's format, else png.
  --sheet <sheet>                Sheet to render. Default: every visible sheet, at most 20 per run.
  --range <range>                Render only this range, e.g. A1:G20 or Sales!A1:G20.
  --all-sheets                   Render every visible sheet, one image per sheet named <out-base>.<Sheet><ext>.
  --dpi <dpi>                    Raster resolution; ignored for vector formats. Range: 36-1200. [default: 192]
  -o, --out <out>                Output path. Default: the input path with the image extension. Several sheets write <stem>.<sheet>.<ext> beside it.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells render book.xlsx --range Sales!A1:G20 --out sales.png
  aspose-cli cells render book.xlsx --sheet Dashboard --out dashboard.png
  aspose-cli cells render book.xlsx --all-sheets --out check.png
