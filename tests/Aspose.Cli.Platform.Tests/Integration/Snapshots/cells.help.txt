## aspose-cli cells --help
Description:
  Read, edit, convert and render workbooks through the Aspose.Cells object model.

Usage:
  aspose-cli cells [command]

Commands:
  read <file>     Read a workbook's objects, each with every row of the object table, and its inventory.
  search <file>   Search the text of a workbook's cells, as their number formats show it, their formulas and their comments; each hit names the object's address and row.
  create <file>   Create a workbook: the engine's new workbook, or a copy of a template saved in the output's format.
  edit <file>     Apply a batch of set, add, delete, move and do operations to a workbook; nothing is written when one fails.
  convert <file>  Convert a workbook, or CSV or TSV text, to another format with the engine's options for it. An html, mhtml or md output is one file: it holds its images itself (SaveAsSingleFile, ExportImagesAsBase64).
  render <file>   Render sheets, or an area of one, to images as the engine draws them.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells read book.xlsx
  aspose-cli cells read book.xlsx --at "sheet/Sales 2026/range/A1:F6"
  aspose-cli cells edit book.xlsx --ops ops.json --out revised.xlsx

Learn more:
  aspose-cli schema v2/cells/ops --operation directory  the object table: kinds, addresses, rows, adds and actions


## aspose-cli cells convert --help
Description:
  Convert a workbook, or CSV or TSV text, to another format with the engine's options for it. An html, mhtml or md output is one file: it holds its images itself (SaveAsSingleFile, ExportImagesAsBase64).

Usage:
  aspose-cli cells convert <file> [options]

Arguments:
  <file>  Workbook file path.

Options:
  --to <to>                            Target format: xlsx, xltx, xlsm, xltm, xlam, xlsb, xls, xlt, csv, tsv, ods, html, mhtml, pdf, xps, json, md. Default: the --out extension's format.
  --sheet <sheet>                      A sheet to write, by its name: one for a csv, tsv or md output, which otherwise holds the sheet the engine writes, the active sheet; any for pdf, repeated. Other formats write the whole workbook.
  --format-strategy <format-strategy>  How a csv, tsv or md output writes cell values, a member name of the engine's CellValueFormatStrategy: None writes the values as they are stored, DisplayString as the number formats show them. Default: the engine's.
  --separator <separator>              The separator of a .csv or .txt input, one character (TxtLoadOptions.Separator). Required for such an input; a .tsv input is tab-separated.
  --encoding <encoding>                The text encoding of a .csv, .tsv or .txt input, such as utf-8, gb18030 or windows-1252 (TxtLoadOptions.Encoding). Required for such an input.
  --convert-numbers                    true or false: whether a .csv, .tsv or .txt input's numbers become numbers (TxtLoadOptions.ConvertNumericData). Required for such an input.
  --convert-dates                      true or false: whether a .csv, .tsv or .txt input's dates become dates (TxtLoadOptions.ConvertDateTimeData). Required for such an input.
  --culture <culture>                  The culture a text input's numbers and dates are read in, such as en-US or de-DE (LoadOptions.CultureInfo). Required when --convert-numbers or --convert-dates is true.
  --bom                                Start a csv or tsv output with a UTF-8 byte order mark, so Excel reads its non-English text correctly. Default: UTF-8 without one.
  -o, --out <out>                      Output path. Default: the input path with the target extension (with '.out' inserted when that would overwrite the input).
  --overwrite                          Replace the output file if it already exists.
  --dry-run                            Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>                Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>        Name of an environment variable holding the password for the workbook.
  --password-stdin                     Read the password for the workbook from the first line of stdin.
  --encrypt <encrypt>                  Password for the output workbook. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>          Name of an environment variable holding the password for the output workbook.
  --encrypt-stdin                      Read the password for the output workbook from the first line of stdin.
  --font-dir <font-dir>                Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells convert book.xlsx --out report.pdf
  aspose-cli cells convert book.xlsx --to csv --sheet Sales --format-strategy None --out sales.csv
  aspose-cli cells convert sales.csv --to xlsx --separator , --encoding utf-8 --convert-numbers true --convert-dates false
  aspose-cli cells convert export.csv --to xlsx --separator ; --encoding windows-1252 --convert-numbers true --convert-dates true --culture de-DE

Learn more:
  aspose-cli docs cells/overview  what each Cells command is for

## aspose-cli cells edit --help
Description:
  Apply a batch of set, add, delete, move and do operations to a workbook; nothing is written when one fails.

Usage:
  aspose-cli cells edit <file> --ops <ops> [options]

Arguments:
  <file>  Workbook file path.

Options:
  --ops <ops> (REQUIRED)         The operation document, {"ops": [...]}: a path to it, '-' to read it from stdin, or the document itself when the value starts with { (inline). At most 10000 operations; each is a set, add, delete, move or do. The kinds, rows, adds and actions: aspose-cli schema v2/cells/ops --operation directory; one of them in full: aspose-cli schema v2/cells/ops --operation <name>.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.
  --encrypt <encrypt>            Password for the output workbook. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output workbook.
  --encrypt-stdin                Read the password for the output workbook from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells edit book.xlsx --ops ops.json --out revised.xlsx
  aspose-cli cells edit book.xlsx --in-place --ops ops.json

Learn more:
  aspose-cli schema v2/cells/ops --operation directory  the kinds and their rows, the adds and the actions an operation names
  aspose-cli schema v2/cells/ops --operation <name>     one kind, add or action in full
  aspose-cli docs cells/overview                        addresses, the five operation shapes and the read-back


## aspose-cli cells read --help
Description:
  Read a workbook's objects, each with every row of the object table, and its inventory.

Usage:
  aspose-cli cells read <file> [options]

Arguments:
  <file>  Workbook file path.

Options:
  --at <at>                      The address of the object to read with everything below it, as read gives it in at. Default: the whole document.
  --from <from>                  The address of the object the window starts at; a truncated read's window.next gives it.
  --kind <kind>                  List only objects of this kind, one the ops schema lists; repeat for several. Default: every kind. Objects of the kinds row, column, cell, style, point are listed only when --kind names them; window.notListedUnlessNamed names those a read left out.
  --max-objects <max-objects>    The most objects one window lists. Range: 1-10000. [default: 200]
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells read book.xlsx
  aspose-cli cells read book.xlsx --at "sheet/Sales 2026/range/A1:F6"
  aspose-cli cells read book.xlsx --at "sheet/Sales 2026" --kind cell

Learn more:
  aspose-cli schema v2/cells/ops --operation directory  the kinds an address and --kind name, with their rows
  aspose-cli docs cells/overview                        addresses, windows and the inventory


## aspose-cli cells render --help
Description:
  Render sheets, or an area of one, to images as the engine draws them.

Usage:
  aspose-cli cells render <file> [options]

Arguments:
  <file>  Workbook file path.

Options:
  --to <jpeg|png|svg>            Image format. Default: the --out extension's format, else png.
  --sheet <sheet>                A sheet to render, by its name; repeat for several. Default: every sheet of the workbook. Several sheets are each written to <stem>.<sheet>.<ext>.
  --area <area>                  An area of the one sheet named, such as A1:G20, set as its print area and drawn alone. Default: the whole sheet.
  --dpi <dpi>                    Raster resolution; refused for vector output such as svg. Range: 36-1200. [default: 192]
  -o, --out <out>                Output path. Default: the input path with the image extension. Several sheets write <stem>.<sheet>.<ext> beside it.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the workbook.
  --password-stdin               Read the password for the workbook from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells render book.xlsx --out book.png
  aspose-cli cells render book.xlsx --sheet Dashboard --area A1:H30 --out dashboard.png
  aspose-cli cells render book.xlsx --sheet Data --sheet Summary --out check.png

Learn more:
  aspose-cli docs cells/overview  what each Cells command is for


## aspose-cli cells search --help
Description:
  Search the text of a workbook's cells, as their number formats show it, their formulas and their comments; each hit names the object's address and row.

Usage:
  aspose-cli cells search <file> --pattern <pattern> [options]

Arguments:
  <file>  Workbook file path.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --password <password>           Password for the workbook. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the workbook.
  --password-stdin                Read the password for the workbook from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli cells search book.xlsx --pattern Total
  aspose-cli cells search book.xlsx --pattern "SUM\(" --regex

Learn more:
  aspose-cli docs cells/overview  what each Cells command is for
