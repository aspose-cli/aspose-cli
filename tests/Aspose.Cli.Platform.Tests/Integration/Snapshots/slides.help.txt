## aspose-cli slides --help
Description:
  Presentation automation with slide, layout and notes semantics.

Usage:
  aspose-cli slides [command]

Commands:
  inspect <file>  Show presentation structure, stable slide ids and metadata.
  read <file>     Read a bounded slide-content window.
  search <file>   Search presentation shape and speaker-notes text.
  convert <file>  Convert a presentation or selected slides.
  render <file>   Render one or more slides for visual verification.
  create <file>   Create a blank, template-based or Markdown-authored presentation.
  edit <file>     Apply one validated, atomic presentation operation batch.
  extract <file>  Extract bounded presentation media, notes or text.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides create deck.pptx --from-markdown outline.md --template brand.pptx
  aspose-cli slides inspect deck.pptx --sample --detail masters layouts fonts notes
  aspose-cli slides read deck.pptx --slides 1-5 --content full --notes --output-format json
  aspose-cli slides edit deck.pptx --ops deck-ops.json --out revised.pptx
  aspose-cli review revised.pptx --out revised.review

Learn more:
  aspose-cli docs slides/editing       atomic presentation operations
  aspose-cli docs slides/verification  slide read-back and visual review
  aspose-cli schema v2/slides/ops      the operation JSON schema


## aspose-cli slides convert --help
Description:
  Convert a presentation or selected slides.

Usage:
  aspose-cli slides convert <file> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --to <to>                      Target presentation export format; 'slides render' writes slide images. Default: the --out extension's format. Values: gif, html, html5, md, odp, pdf, ppt, pptm, pptx, tiff, xps.
  --slides <slides>              Slides to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every slide.
  -o, --out <out>                Output path; defaults to a sibling using the target extension.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.
  --encrypt <encrypt>            Password for the output presentation. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output presentation.
  --encrypt-stdin                Read the password for the output presentation from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides convert deck.pptx --out deck.pdf
  aspose-cli slides convert deck.pptx --slides 1-3 --out handout.pdf
  aspose-cli slides convert deck.pptx --to html5 --out site/deck.html

Learn more:
  aspose-cli docs slides/overview  what each Slides command is for

## aspose-cli slides edit --help
Description:
  Apply one validated, atomic presentation operation batch.

Usage:
  aspose-cli slides edit <file> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --ops <ops>                    The ops JSON, an object with ops or the bare array of operations: a path to the document, '-' to read it from stdin, or the document itself when the value starts with { or [ (inline). To name a file whose name starts with '[', prefix it with ./ . At most 10000 operations. Vocabulary: aspose-cli schema v2/slides/ops.
  --if-match <if-match>          Require the current input SHA-256 fingerprint before editing.
  --best-effort                  Keep successful operations, report failures, and exit 8.
  --verify                       Read the staged output back and check the slide order, titles, shape text, body paragraphs, notes, layouts, hidden slides, footers, transitions, sections, properties, slide size and replaced text each operation left.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --backup                       Create a non-overwriting backup before an in-place write.
  --dry-run                      Check the input, the output and the operations, and apply the operations in memory, without writing any file. A dry run that succeeds does not guarantee that the edit succeeds.
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.
  --encrypt <encrypt>            Password for the output presentation. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output presentation.
  --encrypt-stdin                Read the password for the output presentation from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides edit deck.pptx --ops deck-ops.json --out revised.pptx --verify
  aspose-cli slides edit deck.pptx --in-place --backup --ops deck-ops.json

Learn more:
  aspose-cli docs slides/editing       atomic presentation operations
  aspose-cli schema v2/slides/ops      the operation JSON schema
  aspose-cli docs slides/verification  what --verify reads back

## aspose-cli slides search --help
Description:
  Search presentation shape and speaker-notes text.

Usage:
  aspose-cli slides search <file> --pattern <pattern> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --scope <all|notes|shapes>      Search scope: the shape text, the speaker notes or both. [default: all]
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --password <password>           Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the presentation.
  --password-stdin                Read the password for the presentation from the first line of stdin.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides search deck.pptx --pattern TODO --output-format json
  aspose-cli slides search deck.pptx --pattern "Q[1-4]" --regex --scope notes
