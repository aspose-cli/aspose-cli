## aspose-cli slides --help
Description:
  Read, edit, convert and render presentations through the Aspose.Slides object model.

Usage:
  aspose-cli slides [command]

Commands:
  read <file>     Read a presentation's objects, each with every row of the object table, and its inventory.
  search <file>   Search the text of a presentation's shapes, table cells, notes and chart titles; each hit names the object's address.
  convert <file>  Convert a presentation or selected slides.
  render <file>   Render one or more slides for visual verification.
  create <file>   Create a presentation: the engine's new presentation, or a copy of a template saved in the output's format.
  edit <file>     Apply a batch of set, add, delete, move and do operations to a presentation; nothing is written when one fails.
  extract <file>  Extract the media a presentation embeds, byte for byte.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides create deck.pptx --template brand.potx
  aspose-cli slides read deck.pptx --kind slide --kind shape
  aspose-cli slides read deck.pptx --at slide/256
  aspose-cli slides edit deck.pptx --ops ops.json --out revised.pptx

Learn more:
  aspose-cli schema v2/slides/ops/directory  the object table: kinds, addresses, rows, adds and actions


## aspose-cli slides convert --help
Description:
  Convert a presentation or selected slides.

Usage:
  aspose-cli slides convert <file> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --to <to>                      Target presentation export format; 'slides render' writes slide images. Default: the --out extension's format. html5 writes .html or .htm. Values: gif, html, html5, md, odp, pdf, ppt, pptm, pptx, xps.
  --slides <slides>              Slides to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every slide.
  -o, --out <out>                Output path; defaults to a sibling using the target extension.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.
  --encrypt <encrypt>            Password for the output presentation. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output presentation.
  --encrypt-stdin                Read the password for the output presentation from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides convert deck.pptx --out deck.pdf
  aspose-cli slides convert deck.pptx --slides 1-3 --out handout.pdf
  aspose-cli slides convert deck.pptx --to html5 --out site/deck.html

Learn more:
  aspose-cli schema v2/slides/convert-result  the fields of the convert result

## aspose-cli slides edit --help
Description:
  Apply a batch of set, add, delete, move and do operations to a presentation; nothing is written when one fails.

Usage:
  aspose-cli slides edit <file> --ops <ops> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --ops <ops> (REQUIRED)         The operation document, {"ops": [...]}: a path to it, '-' to read it from stdin, or the document itself when the value starts with { (inline). At most 10000 operations; each is a set, add, delete, move or do. The kinds, rows, adds and actions: aspose-cli schema v2/slides/ops/directory; one of them in full: aspose-cli schema v2/slides/ops/<name>.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.
  --encrypt <encrypt>            Password for the output presentation. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output presentation.
  --encrypt-stdin                Read the password for the output presentation from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides edit deck.pptx --ops ops.json --out revised.pptx
  aspose-cli slides edit deck.pptx --in-place --ops ops.json

Learn more:
  aspose-cli schema v2/slides/ops/directory  the kinds and their rows, the adds and the actions an operation names
  aspose-cli schema v2/slides/ops/<name>     one kind, add or action in full
  aspose-cli schema v2/slides/edit-result    the fields of the edit result

## aspose-cli slides read --help

  aspose-cli slides read <file> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --at <at>                      The address of the object to read with everything below it, as read gives it in at. Default: the whole document.

  --kind <kind>                  List only objects of this kind, one the ops schema lists; repeat for several. Default: every kind.
  --max-objects <max-objects>    The most objects one window lists. Range: 1-10000. [default: 200]
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.

  aspose-cli slides read deck.pptx

## aspose-cli slides render --help
Description:
  Render one or more slides for visual verification.

Usage:
  aspose-cli slides render <file> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --to <jpeg|png|svg|tiff>       Image format. Default: the --out extension's format, else png.
  --slides <slides>              Slides to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every slide; at most 20 per run.
  --dpi <dpi>                    Raster resolution; refused for vector output such as svg. Range: 36-1200. [default: 192]
  --width <width>                Exact raster width in pixels; replaces --dpi and is refused for vector output such as svg. Range: 64-20000.
  -o, --out <out>                Output path. Default: the input path with the image extension. Several slides write <stem>.<slide>.<ext> beside it.
  --overwrite                    Replace the output file if it already exists.
  --dry-run                      Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>          Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the presentation.
  --password-stdin               Read the password for the presentation from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides render deck.pptx --slides 1-3 --out slide.png
  aspose-cli slides render deck.pptx --slides 2 --width 1920 --out hero.png

Learn more:
  aspose-cli schema v2/slides/render-result  the fields of the render result


## aspose-cli slides search --help
Description:
  Search the text of a presentation's shapes, table cells, notes and chart titles; each hit names the object's address.

Usage:
  aspose-cli slides search <file> --pattern <pattern> [options]

Arguments:
  <file>  Presentation file path.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --password <password>           Password for the presentation. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the presentation.
  --password-stdin                Read the password for the presentation from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli slides search deck.pptx --pattern TODO
  aspose-cli slides search deck.pptx --pattern "Q[1-4]" --regex

Learn more:
  aspose-cli schema v2/slides/search-result  the fields of the search result
