## aspose-cli slides --help
Description:
  Presentation automation with slide, layout and notes semantics.

Usage:
  aspose-cli slides [command] [options]

Options:
  -?, -h, --help                              Show help and usage information
  -f, --output <compact|json|markdown|table>  Output format: json (contract envelopes), compact (the same JSON on one line), table (human text) or markdown. Default: table on a terminal, json when redirected.
  -q, --quiet                                 Suppress warnings and notices on stderr (errors still print).
  -v, --verbose                               Emit structured JSONL diagnostics (timing, error codes) to stderr; stdout is untouched.
  --license <license>                         Path to an Aspose license file; overrides every other license source.
  --license-mode <auto|evaluation>            auto (default) resolves the license sources in order; evaluation reads none of them and runs this command in evaluation mode. Cannot be combined with --license.
  --workdir <workdir>                         Base directory for relative paths. Default: the current directory.
  --timeout <timeout>                         Set one command deadline in seconds. Before exit 9, supervised work is stopped and staged outputs are recovered.
  --max-input-bytes <max-input-bytes>         Maximum bytes admitted for one input before product runtime initialization (default 1073741824; hard maximum 4294967296).

Commands:
  inspect <file>  Show presentation structure, stable slide ids and metadata.
  query           Read bounded presentation projections without mutating the source.
  convert <file>  Convert a presentation or selected slides.
  render <file>   Render one or more slides for visual verification.
  create <file>   Create a blank, template-based or Markdown-authored presentation.
  edit <file>     Apply one validated, atomic presentation operation batch.
  extract <file>  Extract bounded presentation media, notes or text.

Examples:
  aspose-cli slides create deck.pptx --from-markdown outline.md --template brand.pptx
  aspose-cli slides inspect deck.pptx --preview --detail masters layouts fonts notes
  aspose-cli slides query slides deck.pptx --slides 1-5 --scope full --notes --output json
  aspose-cli slides edit deck.pptx --ops deck-ops.json --out revised.pptx
  aspose-cli review revised.pptx --out revised.review

Learn more:
  aspose-cli docs slides/editing       atomic presentation operations
  aspose-cli docs slides/verification  slide read-back and visual review
  aspose-cli schema v2/slides/ops      the operation JSON schema
