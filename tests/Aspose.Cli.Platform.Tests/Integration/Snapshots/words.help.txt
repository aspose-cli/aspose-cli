## aspose-cli words --help
Description:
  Word-processing document automation with layout fidelity.

Usage:
  aspose-cli words [command]

Commands:
  inspect <file>          Show document structure, safety state and metadata.
  read <file>             Read a bounded, stable window of document blocks.
  search <file>           Search bounded document scopes with regex timeout protection.
  convert <file>          Convert a document using the detected input format.
  render <file>           Render one or more document pages.
  create <file>           Create a document from at most one content source, optionally inside a template; without either it is blank.
  edit <file>             Apply one validated, atomic Words operation batch.
  compare <left> <right>  Semantically compare two documents and optionally save a redline.
  split <file>            Split a document into safe, deterministically named DOCX files.
  extract <file>          Extract bounded document assets.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words inspect contract.docx --detail outline --detail sections
  aspose-cli words read contract.docx --blocks 1-30 --content full

Learn more:
  aspose-cli docs words/editing       the document block model and edit operations
  aspose-cli docs words/verification  read-back, semantic and visual verification
  aspose-cli schema v2/words/ops      the operation JSON schema


## aspose-cli words compare --help
Description:
  Semantically compare two documents and optionally save a redline.

Usage:
  aspose-cli words compare <left> <right> [options]

Arguments:
  <left>   Original document.
  <right>  Changed document.

Options:
  --ignore-formatting                        Ignore formatting-only changes.
  --granularity <char|word>                  Unit a change is marked in; use the character unit for Chinese or Japanese text. [default: word]
  --author <author>                          Author of the redline's revisions. Default: Aspose CLI.
  -o, --out <out>                            Optional redline output; its extension selects the format, such as .docx or .pdf.
  --overwrite                                Replace the output file if it already exists.
  --dry-run                                  Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --left-password <left-password>            Password for the original document. Discouraged: visible in the process list; prefer --left-password-env.
  --left-password-env <left-password-env>    Name of an environment variable holding the password for the original document.
  --left-password-stdin                      Read the password for the original document from the first line of stdin.
  --right-password <right-password>          Password for the changed document. Discouraged: visible in the process list; prefer --right-password-env.
  --right-password-env <right-password-env>  Name of an environment variable holding the password for the changed document.
  --right-password-stdin                     Read the password for the changed document from the first line of stdin.
  --font-dir <font-dir>                      Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words compare original.docx changed.docx --output-format json
  aspose-cli words compare original.docx changed.docx --out redline.docx --author "Legal Review"

Learn more:
  aspose-cli docs words/revisions  tracked changes and redlines

## aspose-cli words edit --help
Description:
  Apply one validated, atomic Words operation batch.

Usage:
  aspose-cli words edit <file> [options]

Arguments:
  <file>  Document to edit.

Options:
  --ops <ops>                    The ops JSON, an object with ops or the bare array of operations: a path to the document, '-' to read it from stdin, or the document itself when the value starts with { or [ (inline). To name a file whose name starts with '[', prefix it with ./ . At most 10000 operations. Vocabulary: aspose-cli schema v2/words/ops.
  --set <set>                    Replace a bookmark's text as bookmark:NAME=TEXT; repeatable, applied after the --ops document. Example: --set "bookmark:ClientName=Contoso Ltd.".
  --if-match <if-match>          Require the current input SHA-256 fingerprint before editing.
  --best-effort                  Keep successful operations, report failures, and exit 8.
  --verify                       Compare the staged document after save and reopen to report semantic verification.
  --track-changes                Track this batch as revisions.
  --author <author>              Revision author; required with --track-changes.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --backup                       Create a non-overwriting backup before an in-place write.
  --dry-run                      Check the input, the output and the operations, and apply the operations in memory, without writing any file. A dry run that succeeds does not guarantee that the edit succeeds.
  --password <password>          Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the document.
  --password-stdin               Read the password for the document from the first line of stdin.
  --encrypt <encrypt>            Password for the output document. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output document.
  --encrypt-stdin                Read the password for the output document from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words edit contract.docx --in-place --backup --verify --set "bookmark:Client=Contoso"
  aspose-cli words edit contract.docx --in-place --backup --ops ops.json --verify

Learn more:
  aspose-cli docs words/editing   addressing and operation recipes
  aspose-cli schema v2/words/ops  the exact edit-batch contract

## aspose-cli words search --help
Description:
  Search bounded document scopes with regex timeout protection.

Usage:
  aspose-cli words search <file> --pattern <pattern> [options]

Arguments:
  <file>  Document to open.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --scope <scope>                 Search scope: body (the main text, without the comments and footnotes it anchors), headers-footers, footnotes (with endnotes), comments or all. [default: body]
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --password <password>           Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the document.
  --password-stdin                Read the password for the document from the first line of stdin.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words search contract.docx --pattern TODO --scope all
  aspose-cli words search contract.docx --pattern "Section\s+\d+" --regex --max-hits 20

## aspose-cli words split --help
Description:
  Split a document into safe, deterministically named DOCX files.

Usage:
  aspose-cli words split <file> --by <by> --out-dir <out-dir> [options]

Arguments:
  <file>  Document to open.

Options:
  --by <heading1|pages|sections> (REQUIRED)  How to divide the document: one part per Heading 1, after a leading part for any blocks before the first; one part per page or per --every N of them; one part per section.
  --every <every>                            Pages per part with --by pages. Default: 1.
  --pages <pages>                            Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page. Only with --by pages.
  --out-dir <out-dir> (REQUIRED)             Directory that receives the parts, named <stem>.<n>.docx.
  --overwrite                                Replace the output file if it already exists.
  --dry-run                                  Check the input, the output and the options, then stop without running the command or writing any file. A dry run that succeeds does not guarantee that the command succeeds.
  --password <password>                      Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>              Name of an environment variable holding the password for the document.
  --password-stdin                           Read the password for the document from the first line of stdin.
  --encrypt <encrypt>                        Password for every part. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>                Name of an environment variable holding the password for every part.
  --encrypt-stdin                            Read the password for every part from the first line of stdin.
  --font-dir <font-dir>                      Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -q/--quiet, -v/--verbose, --license, --license-mode, --workdir, --timeout, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words split report.docx --by heading1 --out-dir chapters
  aspose-cli words split report.docx --by pages --pages 1-3,8 --out-dir excerpts
