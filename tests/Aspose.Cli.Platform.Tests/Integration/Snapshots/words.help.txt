## aspose-cli words --help
Description:
  Read, edit, convert and render documents through the Aspose.Words object model.

Usage:
  aspose-cli words [command]

Commands:
  read <file>             Read a document's objects, each with every row of the object table, and its inventory.
  search <file>           Search the text of a document's paragraphs, as Paragraph.GetText() gives it; each hit names the paragraph's address.
  create <file>           Create a document: the engine's new document, or a copy of a template saved in the output's format.
  edit <file>             Apply a batch of set, add, delete, move and do operations to a document; nothing is written when one fails.
  convert <file>          Convert a document to another format with the engine's options for it. An html, html-fixed or md output is one file: it holds its images, fonts and styles itself.
  render <file>           Render one or more document pages.
  compare <left> <right>  Compare a changed document with the original, Document.Compare, and write the redline: a copy of the original whose revisions are the differences.
  extract <file>          Write the bytes of each image the document stores, ImageData.ImageBytes, one file per image in document order; a linked image stores none.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words read contract.docx
  aspose-cli words read contract.docx --at section/0/body/range
  aspose-cli words edit contract.docx --ops ops.json --out revised.docx

Learn more:
  aspose-cli schema v3/words/ops/directory  the object table: kinds, addresses, rows, adds and actions


## aspose-cli words compare --help
Description:
  Compare a changed document with the original, Document.Compare, and write the redline: a copy of the original whose revisions are the differences.

Usage:
  aspose-cli words compare <left> <right> --author <author> --date-time <date-time> [options]

Arguments:
  <left>   Original document.
  <right>  Changed document.

Options:
  --author <author> (REQUIRED)               The author of the redline's revisions, Document.Compare's author.
  --date-time <date-time> (REQUIRED)         The date and time of the redline's revisions, Document.Compare's dateTime, written yyyy-MM-ddTHH:mm:ss.
  --granularity <granularity>                CompareOptions.Granularity, a member name of the engine's Granularity, such as WordLevel or CharLevel. Default: the engine's.
  --ignore-formatting                        Set CompareOptions.IgnoreFormatting to true.
  --ignore-case-changes                      Set CompareOptions.IgnoreCaseChanges to true.
  --ignore-comments                          Set CompareOptions.IgnoreComments to true.
  --ignore-tables                            Set CompareOptions.IgnoreTables to true.
  --ignore-fields                            Set CompareOptions.IgnoreFields to true.
  --ignore-footnotes                         Set CompareOptions.IgnoreFootnotes to true.
  --ignore-textboxes                         Set CompareOptions.IgnoreTextboxes to true.
  --ignore-headers-and-footers               Set CompareOptions.IgnoreHeadersAndFooters to true.
  -o, --out <out>                            The redline's path; its extension selects the format, such as .docx or .pdf.
  --overwrite                                Replace the output file if it already exists.
  --left-password <left-password>            Password for the original document. Discouraged: visible in the process list; prefer --left-password-env.
  --left-password-env <left-password-env>    Name of an environment variable holding the password for the original document.
  --left-password-stdin                      Read the password for the original document from the first line of stdin.
  --right-password <right-password>          Password for the changed document. Discouraged: visible in the process list; prefer --right-password-env.
  --right-password-env <right-password-env>  Name of an environment variable holding the password for the changed document.
  --right-password-stdin                     Read the password for the changed document from the first line of stdin.
  --font-dir <font-dir>                      Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words compare original.docx changed.docx --author "Legal Review" --date-time 2026-03-01T09:00:00 --out redline.docx
  aspose-cli words compare original.docx changed.docx --author Review --date-time 2026-03-01T09:00:00 --ignore-formatting --granularity CharLevel --out redline.pdf

Learn more:
  aspose-cli schema v3/words/compare-result  the fields of the compare result


## aspose-cli words convert --help
Description:
  Convert a document to another format with the engine's options for it. An html, html-fixed or md output is one file: it holds its images, fonts and styles itself.

Usage:
  aspose-cli words convert <file> [options]

Arguments:
  <file>  Document to open.

Options:
  --to <to>                            Target document format. Default: the --out extension's format. flatopc, wordml write .xml; openxps writes .oxps; html-fixed writes .html or .htm. Values: azw3, doc, docm, docx, dot, dotm, dotx, epub, flatopc, html, html-fixed, md, mhtml, mobi, odt, openxps, ott, pcl, pdf, ps, rtf, txt, wordml, xps.
  --pages <pages>                      Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page. Only with --to pdf, xps, openxps, ps, pcl or html-fixed.
  --encoding <encoding>                The text encoding of a txt or md input, such as utf-8, gb18030 or windows-1252 (LoadOptions.Encoding). Required for such an input.
  --auto-numbering-detection           true or false: TxtLoadOptions.AutoNumberingDetection of a txt input. Required for such an input.
  --detect-numbering-with-whitespaces  true or false: TxtLoadOptions.DetectNumberingWithWhitespaces of a txt input. Required for such an input.
  --detect-hyperlinks                  true or false: TxtLoadOptions.DetectHyperlinks of a txt input. Required for such an input.
  --leading-spaces <leading-spaces>    TxtLoadOptions.LeadingSpacesOptions of a txt input, a member name of the engine's TxtLeadingSpacesOptions, such as ConvertToIndent, Preserve or Trim. Required for such an input.
  -o, --out <out>                      Output path; defaults to a sibling using the target extension.
  --overwrite                          Replace the output file if it already exists.
  --password <password>                Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>        Name of an environment variable holding the password for the document.
  --password-stdin                     Read the password for the document from the first line of stdin.
  --encrypt <encrypt>                  Password for the output document. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>          Name of an environment variable holding the password for the output document.
  --encrypt-stdin                      Read the password for the output document from the first line of stdin.
  --font-dir <font-dir>                Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words convert contract.docx --to pdf
  aspose-cli words convert contract.docx --to pdf --pages 1-3 --out excerpt.pdf
  aspose-cli words convert notes.md --to docx --encoding utf-8
  aspose-cli words convert notes.txt --to docx --encoding utf-8 --auto-numbering-detection false --detect-numbering-with-whitespaces false --detect-hyperlinks false --leading-spaces Preserve

Learn more:
  aspose-cli schema v3/words/convert-result  the fields of the convert result

## aspose-cli words edit --help
Description:
  Apply a batch of set, add, delete, move and do operations to a document; nothing is written when one fails.

Usage:
  aspose-cli words edit <file> --ops <ops> [options]

  <file>  Document to open.

Options:
  --ops <ops> (REQUIRED)         The operation document, {"ops": [...]}: a path to it, '-' to read it from stdin, or the document itself when the value starts with { (inline). At most 10000 operations; each is a set, add, delete, move or do. The kinds, rows, adds and actions: aspose-cli schema v3/words/ops/directory; one of them in full: aspose-cli schema v3/words/ops/<name>.
  -o, --out <out>                Output path. Default: the input path with '.out' inserted before the extension.
  --overwrite                    Replace the output file if it already exists.
  --in-place                     Modify the input file itself atomically.
  --password <password>          Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the document.
  --password-stdin               Read the password for the document from the first line of stdin.
  --encrypt <encrypt>            Password for the output document. Discouraged: visible in the process list; prefer --encrypt-env.
  --encrypt-env <encrypt-env>    Name of an environment variable holding the password for the output document.
  --encrypt-stdin                Read the password for the output document from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words edit contract.docx --ops ops.json --out revised.docx
  aspose-cli words edit contract.docx --in-place --ops ops.json

Learn more:
  aspose-cli schema v3/words/ops/directory  the kinds and their rows, the adds and the actions an operation names
  aspose-cli schema v3/words/ops/<name>     one kind, add or action in full
  aspose-cli schema v3/words/edit-result    the fields of the edit result

## aspose-cli words read --help
Description:
  Read a document's objects, each with every row of the object table, and its inventory.

Usage:
  aspose-cli words read <file> [options]

Arguments:
  <file>  Document to open.

Options:
  --at <at>                      The address of the object to read with everything below it, as read gives it in at. Default: the whole document.
  --from <from>                  The address of the object the window starts at; a truncated read's window.next gives it.
  --kind <kind>                  List only objects of this kind, one the ops schema lists; repeat for several. Default: every kind. Objects of the kinds paragraph, run, field, shape, row, cell, bookmark, style, listLevel, revision are listed only when --kind names them; window.notListedUnlessNamed names those a read left out.
  --max-objects <max-objects>    The most objects one window lists. Range: 1-10000. [default: 200]
  --password <password>          Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the document.
  --password-stdin               Read the password for the document from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words read contract.docx
  aspose-cli words read contract.docx --kind paragraph --max-objects 40
  aspose-cli words read contract.docx --at section/0/body/range
  aspose-cli words read contract.docx --at section/0/body/table/0 --kind cell --kind paragraph --kind run

Learn more:
  aspose-cli schema v3/words/ops/directory  the kinds an address and --kind name, with their rows
  aspose-cli schema v3/words/read-result    the fields of the read result


## aspose-cli words render --help
Description:
  Render one or more document pages.

Usage:
  aspose-cli words render <file> [options]

Arguments:
  <file>  Document to open.

Options:
  --to <jpeg|png|svg>            Image format. Default: the --out extension's format, else png.
  --pages <pages>                Pages to process: 1-based numbers and ranges such as 1-3,7,9-, or all. Default: every page; at most 20 per run.
  --dpi <dpi>                    Raster resolution; refused for vector output such as svg. Range: 36-1200. [default: 192]
  -o, --out <out>                Output path. Default: the input path with the image extension. Several pages write <stem>.<page>.<ext> beside it.
  --overwrite                    Replace the output file if it already exists.
  --password <password>          Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>  Name of an environment variable holding the password for the document.
  --password-stdin               Read the password for the document from the first line of stdin.
  --font-dir <font-dir>          Local font directory searched in addition to the system fonts; repeat for more.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words render contract.docx --pages 1-2 --out review.png
  aspose-cli words render contract.docx --dpi 192 --out review.png

Learn more:
  aspose-cli schema v3/words/render-result  the fields of the render result


## aspose-cli words search --help
Description:
  Search the text of a document's paragraphs, as Paragraph.GetText() gives it; each hit names the paragraph's address.

Usage:
  aspose-cli words search <file> --pattern <pattern> [options]

Arguments:
  <file>  Document to open.

Options:
  --pattern <pattern> (REQUIRED)  Text to find, or a regular expression with --regex.
  --regex                         Treat the pattern as a culture-invariant regular expression with a one-second budget.
  --case-sensitive                Match letter case exactly.
  --max-hits <max-hits>           Maximum returned hits. Range: 1-10000. [default: 100]
  --skip <skip>                   Matches to pass over before the returned hits; a truncated search's window.next sets it. [default: 0]
  --password <password>           Password for the document. Discouraged: visible in the process list; prefer --password-env.
  --password-env <password-env>   Name of an environment variable holding the password for the document.
  --password-stdin                Read the password for the document from the first line of stdin.

Global options:
  -h/--help, --output-format, -v/--verbose, --license, --license-mode, --workdir, --max-input-bytes (see aspose-cli --help)

Examples:
  aspose-cli words search contract.docx --pattern Contoso
  aspose-cli words search contract.docx --pattern "20[0-9]{2}" --regex

Learn more:
  aspose-cli schema v3/words/search-result  the fields of the search result
